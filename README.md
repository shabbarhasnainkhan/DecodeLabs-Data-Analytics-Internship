# 📊 Project 1: Excel Data Cleaning

## 📌 Project Overview

This project focuses on cleaning and preparing a raw dataset using Microsoft Excel. Data cleaning is an essential step in data analysis because accurate and consistent data helps generate reliable insights.

The main objective of this project was to identify data quality issues, clean the dataset, and create a structured version ready for further analysis.

---

## 🎯 Objectives

The key objectives of this project were:

- Understand the structure of raw data
- Identify missing, duplicate, and inconsistent values
- Remove unnecessary data errors
- Standardise data formats
- Improve data quality and consistency
- Prepare a clean dataset for analysis

## 📊 Project Workflow

### 1. Data Understanding
- Reviewed the raw dataset
- Analysed columns, data types, and potential issues

### 2. Data Cleaning
Applied Excel techniques to improve data quality:
- Standardised Headers
- Removed duplicates
- Fixed formatting issues
- Standardised values
- Managed missing information

### 3. Data Validation
- Checked cleaned data for accuracy
- Ensured consistency across columns
- Verified Mathematical Integrity
- Prepared final dataset for analysis

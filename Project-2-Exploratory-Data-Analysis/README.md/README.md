# 📊 Project 2: Exploratory Data Analysis (EDA)

## 📌  Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a dataset to understand the data structure, identify patterns and trends, and extract meaningful insights.

The analysis was performed using Microsoft Excel for data exploration, statistical analysis, and Pivot Table analysis. Microsoft Power BI was then used to create visualisations and an interactive dashboard to present the findings.

## 🎯 Project Objectives

The main objectives of this project were:

- Ask meaningful questions about the dataset before analysis
- Explore the dataset structure, including variables and data types
- Identify trends, patterns, and anomalies within the data
- Use statistical analysis and visualisations to validate observations
- Detect potential data issues and areas for further analysis

## 📁 Dataset Description

The dataset contains order-level information with the following variables:

- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

## 🛠️ Tools Used

- **Microsoft Excel**
  - Data Exploration
  - Descriptive statistical analysis
  - Pivot Table Analysis

- **Microsoft Power BI**
  - Data visualisations
  - Interactive dashboard Creation

## 🔎 Analysis Process

- Explored the dataset structure and variables

- Calculated summary statistics including count, mean, and median

- Analysed patterns using Pivot Tables

- Created an interactive Power BI dashboard to present insights

## 💡 Key Business Insights

- Generated **$1.26M revenue** from **1,200 orders** and **3,535 units sold**

- Identified **June as the highest revenue month** and September as the lowest

- Found **Chairs, Printers, and Laptops** as the top revenue-generating categories

- Identified **Instagram as the strongest referral source**

- Observed that cancelled and returned orders represented **41.41% of total orders**

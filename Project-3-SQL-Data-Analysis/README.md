# 📊 Project 3: SQL Data Analysis

## 📌 Project Overview

This project is the third project of my **DecodeLabs Data Analytics Internship**.

The aim was to use SQL to analyse a sales dataset and extract useful business insights. The analysis was completed using **MySQL**, focusing on sales performance, products, customers, payment methods, referral sources and monthly sales.

This project continues from my previous **Data Cleaning** and **Exploratory Data Analysis** projects, where I worked with the same dataset using Excel and Power BI.

---

## 🎯 Project Objectives

- Analyse sales data using SQL
- Extract meaningful business insights
- Use filtering, sorting and grouping
- Perform basic aggregations
- Analyse sales and customer behaviour
- Identify patterns across products, payments, referrals and months

---

## 📈 Key Business Insights

- **1,200 orders** generated total revenue of **1,264,761.96**.
- There were **1,189 unique customers** and **3,535 items sold**.
- The average order value was **1,053.97**.
- **Chair** was the strongest product, with **562 units sold** and approximately **195,620.11** in revenue.
- **Credit Card** payments generated the highest revenue at **263,847.63**.
- **Instagram** was the highest-performing referral source, generating **275,285.45** in revenue.
- **June** recorded the highest number of orders with **147**, while **September** recorded the lowest with **73**.
- **309 orders** were placed without using a coupon.
